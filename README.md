# Periodontal Classification – Tooth Detection Pipeline

Train a YOLOv8-seg model on the Niihhaa dental OPG dataset to detect, segment,
and number individual teeth, then produce expanded tooth+bone crops for
downstream periodontal disease classification.

## Quick-start

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Convert Niihhaa LabelMe annotations to YOLO-seg format
python scripts/01_convert_labelme_to_yolo.py

# 3. Train the model
python scripts/02_train_model.py

# 4. Run inference on new OPG images
python scripts/03_run_inference.py --input data/input_opgs --output data/output
```

## Project layout

```
config.yaml                       # all paths and hyper-parameters
scripts/
  01_convert_labelme_to_yolo.py   # LabelMe JSON  ➜  YOLO-seg dataset
  02_train_model.py               # YOLOv8m-seg training
  03_run_inference.py             # inference  ➜  crops + JSON
utils/
  fdi_numbering.py                # spatial heuristic for FDI tooth numbers
  crop_utils.py                   # bbox expansion and cropping
data/
  yolo_dataset/                   # generated by script 01
  input_opgs/                     # place your OPG images here
  output/                         # crops, masks, and JSON produced by script 03
```
